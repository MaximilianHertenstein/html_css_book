# CSS: Farben

## Schrift- und Hintergrundfarbe

Mit der Eigenschaft `color` legst du die Schriftfarbe von
HTML-Elementen fest. Mit der Eigenschaft `background-color` legst du
die Hintergrundfarbe fest.

Farben schreibst du als Namen wie `red` oder als Hex-Wert mit `#`
wie `#ff0000` für Rot.


<playground-html-css>

<script type="sample/html">
<link rel="stylesheet" href="style.css">
<p> Hallo Welt </p>
</script>

<script type="sample/css">
p {
    color: white;
    background-color: #ff0000;
}
</script>

</playground-html-css>
